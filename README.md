      <h3>🛡️ NapGuard</h3>
      <p>A lightweight, zero-dependency Python library for validating environment variables. It collects every configuration problem and fails once with a single clear report, so you fix everything in one pass instead of one crash at a time.</p>
      <ul>
        <li><b>Typed getters</b>: <code>require</code>, <code>get_int</code>, <code>get_bool</code>, <code>get_url</code> and <code>get</code> with defaults</li>
        <li><b>All errors at once</b>: <code>validate()</code> raises one <code>ConfigError</code> with a formatted report of every problem</li>
        <li><b>Missing vs empty</b> are reported as distinct problems</li>
        <li><b>Secret-safe</b>: raw values never appear in errors, reports or reprs</li>
        <li><b>Test-friendly</b>: inject a plain dict instead of the real environment</li>
      </ul>
      <p><img src="https://img.shields.io/badge/Python-3.10+-3776AB?style=flat-square&amp;logo=python&amp;logoColor=white"/> <img src="https://img.shields.io/badge/Dependencies-none-2E7D32?style=flat-square"/> <img src="https://img.shields.io/badge/Typed-100%25-1E3A8A?style=flat-square"/></p>
